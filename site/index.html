CISA KEV flags active exploitation. EPSS adds exploitation probability.

From connected to fixed, in four steps.

Built on Trivy, the industry-standard scanner. The scanning stays in your pipeline; the intelligence starts here.

  1. 01

    Connect

    Authorize your Azure DevOps organization in a few clicks, no agents to install. GitHub and GitLab connect the same way.

  2. 02

    Scan with Trivy

    Leavory runs Trivy in your pipeline. Never used Trivy? We hand you a ready-to-use Azure Pipelines template (or GitHub Actions and GitLab CI) that generates the SBOM and scan artifacts.

  3. 03

    Cross-reference

    Every component is correlated against OSV, NVD, GitHub Advisories, CVE.org, CISA KEV, and EPSS using the SBOM and artifact metadata, no source code involved.

  4. 04

    Fix

    Findings ranked by active exploitation (CISA KEV) and exploitation probability (EPSS), with exactly what to change: dependency, version, and manifest.

Leavory never reads your source code.

Trivy, SAST, Sonar, and secret scanning run inside your own pipeline. Leavory only collects their results, SBOM, and scan artifacts. In SaaS, it never touches your repositories at all.
